# Analysis Scripts

These scripts analyze frozen datasets, prediction tables, and checkpoints.

- `analyze_dataset_distribution.py`: dataset coverage and composition statistics.
- `run_sensitivity_analysis.py`: finite-difference temperature sensitivity and phase-path scans.
- `classify_phase_diagram_generalization.py`: held-out-system phase-diagram categories.
- `evaluate_thermodynamic_consistency.py`: chemical-potential and stability diagnostics.
- `evaluate_component_permutation_equivariance.py`: paired Component-2/3
  exchange audit with system-cluster bootstrap intervals.
- `export_figure_2a_results.py`: canonical main-text Figure 2a image.
