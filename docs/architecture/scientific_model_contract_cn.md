# PSMI 科学模型契约

## 目的

本文档定义公开论文、配置、代码和权重之间允许使用的统一术语。它以权威检查点的参数结构和实际前向传播为准，不用论文文字反向推断代码。

## 修正版主模型 `corrected_v2`

| 科学层级 | 实际代码 | 可使用的论文表述 | 不应使用的表述 |
|---|---|---|---|
| 单分子表示 | 共享 `MPNNEncoder`，包含节点与边更新 | 共享权重的分子消息传递编码器 | 未经实现证明的专有编码器名称 |
| 官能团表示 | 官能团 token 编码与共享跨分子多头注意力 | 跨分子官能团注意力 | 温度调制的有序分子对注意力 |
| 混合物表示 | 三节点全连接混合物图及其边特征 | 温度和分子间描述符条件化的混合物图 | 与批处理顺序无关的严格等变图，除非单独验证 |
| 多尺度融合 | 分子、交互、混合物图、官能团和标量特征拼接 | 多尺度特征拼接融合 | Set Transformer 主融合器 |
| 两相输出 | 两个相互独立的三元输出头，各自 softmax | 萃取相与萃余相组成预测头 | 共享逐组分等变输出头 |
| 排列处理 | 交换组分 2/3 的数据增强 | 组分排列增强、排列鲁棒性 | 由结构保证的完整 S3 输出等变性 |
| 物理约束 | NRTL 活度系数下的两相化学势一致性损失 | NRTL 辅助的化学势一致性正则 | 显式 Gibbs–Duhem 损失，除非该权重实际非零 |

## 标量输入契约

- 主基准 `primary_lle`：`[归一化温度, 归一化相路径坐标]`。
- 扩展数据微调 `expanded_lle`：`[归一化温度, 归一化相路径坐标, 归一化压力]`。
- 二维检查点扩展到三维时，新增压力列必须零初始化，并在扩展数据上全参数训练。
- 当前拼接架构的二维/三维版本分别为 4,788,864/4,789,376 个参数；效率结果必须注明所用检查点契约。

## 历史兼容模式

- `FUSION_MODE=tf`：历史名称，实际等价于 `concat`。
- `MIXTURE_NODE_LAYOUT=legacy_component_major`：仅用于复现历史批处理行为。
- `src/psmi_legacy_public/`：只服务旧公开权重，不代表当前主实现。

所有新运行必须使用无歧义名称，并把模型契约写入检查点元数据。
