# Application Case Interface

Application inputs contain three component identifiers or SMILES strings, temperature in kelvin, optional pressure, and optional phase-path sampling settings. Outputs include extract- and raffinate-phase compositions, closure diagnostics, and plot-ready ternary coordinates.

Run `python scripts/run_application_case.py --help` for the complete command-line schema. The industrial case-study datasets and publication figures are organized under `experiments/section_3_results/3_4_industrial_extraction_design/`.
